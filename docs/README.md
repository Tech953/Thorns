The import records exact source members and SHA-256 hashes in [import-manifest.json](import-manifest.json). Source package: `THORNS-RPG-Prototype.zip`. The source package was retained without modifying its original documents.

Original third-party reference-book scans, credentials, save databases and temporary integration work are outside this import.
