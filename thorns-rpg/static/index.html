EXPEDITION LOG / DICE RECEIPTS
    FIELD CODEX / RULES

    D20 + chosen attribute + experience + applicable practice + findings versus difficulty. Practice is proficiency plus equipment, capped at +2. The server displays the full bonus and success chance on each choice. Natural 20 succeeds; natural 1 fails. Each failed check costs 2 shared cohesion. At 0 the expedition withdraws. Field Guide campaigns award XP once per meaningful resolved situation, capped at 3 ordinary XP plus one agreed goal per session. Legacy campaigns retain per-attempt XP. Every 3 earned XP gives +1 to checks, up to +2. Relevant findings add up to +3 on final contact.

    All players vote. When everyone has voted, the most popular choice resolves. Ties are randomly decided by the server. The host can resolve submitted votes early if someone is away. The host selects a specialist before voting; that character makes the check.

    LOCAL DISTANCE / CONSENSUAL PVP

    Positions 0–4, spaced 5 m apart. Contact ≤5 m; near ≤10 m; far 15–20 m. Chapter: one move and local speech per shared turn. Accepted duels alternate actions independently. Open world: Manhattan grid distance, 5 m per tile. Scene travel cancels duels and regroups the party. Party chat is global.
