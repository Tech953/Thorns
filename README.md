# Thorns

Complete saved **Thorns 0.6.0** game project, including all source files, bundled assets, rules, tests, launchers and documentation.

## Play locally

Install Python 3.10 or newer. On Windows, open `thorns-rpg` and double-click `Start-Windows.bat`. On Linux or macOS:

```sh
cd thorns-rpg
python3 server.py
```

Open `http://localhost:8765` and keep the server running. See the [original project instructions](thorns-rpg/README.md) for platform and multiplayer details.

## Included files

- [thorns-rpg/](thorns-rpg/): every file from `THORNS-RPG-Prototype.zip`, preserved byte for byte.
- [docs/README.md](docs/README.md): indexed guides, audits and retained validation records.
- [docs/shared/](docs/shared/): printable character sheet, creature/stat guide and encounter toolkit.
- [upload-manifest.json](upload-manifest.json): source versions, coverage and file checksums.

Historical audits retain their original dates and verification limits. This upload preserves the saved implementation.
